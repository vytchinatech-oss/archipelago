# Архипелаг

Градостроительный и экономический симулятор на островах: стройте города, ведите торговлю с соседями, назначайте министров и удерживайте власть.

## Запуск
Откройте `dist/index.html` в браузере. Пересобрать: `npm run build`.

## Разработка
- `npm test` — сборка и автотесты (Node 20+).
- Код в `src/`, порядок модулей в `build.mjs`.
- Документы: `CLAUDE.md` (правила для Claude), `docs/DESIGN.md` (механики), `docs/STATUS.md` (что дальше), `docs/ARCHITECTURE.md` (устройство кода).
