# Архитектура

Один HTML-файл без зависимостей, Canvas 2D, изометрия. Код разложен по модулям в `src/` и склеивается `build.mjs` в `dist/index.html`.

## Месяц игры (`tick` в `sim/economy.js`)
1. Перепись (`census`): жильё с учётом ореолов, рабочие места, найм по приоритету (ратуша → еда → энергия → службы → добыча → заводы, внутри — ближе к жилью), энергия.
2. Уголь для ТЭС, выработка с факторами: штат, электричество, путь до работы, склад, налог, плодородие, министры.
3. Заводы (сырьё, при нехватке — импорт), потребление жителей, экспорт излишков туда, где выгоднее.
4. Внутренние цены, бюджет, займы, настроение, население и миграция.
5. `natTick` — соседи; `govTick` — министры, показатели, фракции, рейтинг, протесты, выборы.

Торговля по странам копится в `r.xn` (экспорт) и `r.mn` (импорт): `{страна:{ресурс:кр}}` — из них фракции считают отношение к соседям.

Результат месяца — объект `S.rep` (отчёт), в нём `cen` (перепись), `bs` (данные по зданиям), `F` (факторы настроения).

## Тесты
`tests/harness.mjs` грузит CORE+DATA+SIM в `node:vm` и даёт `run(code)`, исполняющий код внутри симуляции. Помощники: `setup(карта, строй, сложность, зерно=1)`, `grid`, `near`, `portUp`.

**Случайность (с 0.5.4).** В `src/sim` нет `Math.random`: всё случайное берётся из `rnd()` — поток партии, его состояние `S.rs` лежит в сохранении. `newGame(mi, seed)` с зерном даёт одну и ту же партию; без зерна — случайное (`newSeed`). Старое сохранение без `rs` получает случайный поток при первом ходе: две загрузки одного старого файла дальше идут по-разному. Тест следит, чтобы `Math.random` в `src/sim` не вернулся.

**Сверка состояния.** `npm run check` (`tools/check-state.mjs`) — список сверки из `OFFICE.md`, 5а, для ворот 0 и 4: итог СХОДИТСЯ / НАХОДКИ / СТОП, коды выхода 0 / 1 / 2. Ключи: `--gate 4`, `--published <версия артефакта>`, `--tests`, `--no-fetch`. Разбор `STATUS.md` проверяет `tests/check-state.test.mjs`: меняя строки «Версия», «Тестов в `main`», замка или «Стопы», правь и скрипт.

**Стратегии и эталон.** `tests/strategies.mjs` — пять стратегий игрока (пассивный, умный + договор, жадный, строитель, «разумная игра»), честный старт, одна метрика скуки, отпечаток состояния. `node tools/strategies.mjs` — таблица 5 × 3 карты × 3 строя × 30 лет; `--compare [файл]` — что изменилось против эталона (по умолчанию `tests/baseline.json`; эталон правил 0.5.3 — `tests/baseline-0.5.3.json`, не переснимается); `--write` — переснять `tests/baseline.json`. В `npm test` партии по 5 лет сверяются с отпечатками `tests/baseline.json` всегда: поменялись правила или бот — тест красный, пока эталон не переснят; в коммит — итог `--compare tests/baseline-0.5.3.json`. Эталон помнит версию Node, на которой снят (поле `node`): отпечатки зависят от дробной арифметики, на другой основной версии тест называет это первым.

**Постоянные защиты** (задача 4 этапа 0а, `tests/guards.test.mjs`; ослабить — только решением заместителя). Версия формата сохранения — одна константа `SAVE_V` (нижняя граница — `SAVE_MIN`) в `core/constants.js`; номер числом пишется только в шагах `migrateSave`; сохранение новее игры, старее `SAVE_MIN` или без версии не открывается. Node закреплён на 22 (`engines`, `.nvmrc`): отпечатки эталона зависят от основной версии; другая — `--write --node-change` и правка обоих мест. Цели `GOALS` несут долю пути `pr` рядом с `ok`; стратегии считают скуку по ней. Число тестов: второй репортёр `tools/count-reporter.mjs` пишет счёт по файлам в `.test-count.json`, `tools/test-count.mjs` сверяет с `tests/test-count.json` — меньше, больше или новый файл без эталона — `npm test` красный; поднять эталон — `node tools/test-count.mjs --write`, опустить — только с `--allow-less` по решению заместителя.

## Правила с этапа 0а (решение CEO 8 ноября 2026)
- **Словарь текстов:** все новые надписи для игрока берутся из словаря по ключу, а не пишутся строкой в коде. Старые тексты переносятся на этапе «М. Готовность к миру». Устройство словаря решается на воротах 1 этапа 0а.
- **Модули дополнений:** механика, которая может стать дополнением, живёт в своём файле `src/data/` и `src/sim/`, включается флагом, добавляет свои поля в `S` с миграцией сохранения; тесты проходят и с модулем, и без него.
