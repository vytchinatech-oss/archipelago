# Архитектура

Один HTML-файл без зависимостей, Canvas 2D, изометрия. Код разложен по модулям в `src/` и склеивается `build.mjs` в `dist/index.html`.

| CORE | `core/util.js` | Генератор случайных чисел, шум, `fmt`, `plural` |
| DATA | `data/rules.js` | Шкалы и все коэффициенты правил (`SCALE`, `RATE`, `RELK`, `ECO`, `MOODK`, `AUTO` и др.), цели. Подключается первым из DATA |

| DATA | `data/buildings.js` | Все здания (`B`), категории, радиусы ореолов (`RAD`) |
| DATA | `data/maps.js` | Три карты и названия областей |
| DATA | `data/nations.js` | Соседи (`NATDEF`) и кризисы (`CRISES`) |

## Месяц игры (`tick` в `sim/economy.js`)
1. Перепись (`census`): жильё с учётом ореолов, рабочие места, найм по приоритету (ратуша → еда → энергия → службы → добыча → заводы, внутри — ближе к жилью), энергия.
2. Уголь для ТЭС, выработка с факторами: штат, электричество, путь до работы, склад, налог, плодородие, министры.
3. Заводы (сырьё, при нехватке — импорт), потребление жителей, экспорт излишков туда, где выгоднее.
4. Внутренние цены, бюджет, займы, настроение, население и миграция.
5. `natTick` — соседи; `govTick` — министры, показатели, фракции, рейтинг, протесты, выборы.

Торговля по странам копится в `r.xn` (экспорт) и `r.mn` (импорт): `{страна:{ресурс:кр}}` — из них фракции считают отношение к соседям.

Результат месяца — объект `S.rep` (отчёт), в нём `cen` (перепись), `bs` (данные по зданиям), `F` (факторы настроения).

## Тесты
`tests/harness.mjs` грузит CORE+DATA+SIM в `node:vm` и даёт `run(code)`, исполняющий код внутри симуляции. Помощники: `setup`, `grid`, `near`, `portUp`.
